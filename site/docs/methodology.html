风险等级评定标准

🟢 绿色（低风险）

满足以下所有条件：
- 不使用用户数据训练模型（默认关闭）
- 数据经过去标识化处理
- 数据留存期限明确且合理（≤30天）
- 用户保留生成内容的版权

🟡 黄色（中风险）

满足以下任一条件：
- 使用用户数据训练，但提供明确的退出机制且操作简单
- 数据留存期限较长（>30天）但可配置
- 去标识化处理不明确

🔴 红色（高风险）

满足以下任一条件：
- 使用用户数据训练且无退出机制或退出困难
- 数据长期留存且无明确删除机制
- 训练场景下未进行去标识化处理（若条款明示不训练，未去标识化本身不构成红色条件，见下方说明）
- 隐私政策模糊，数据使用边界不清晰

关于"未去标识化"的口径（2026-09-19 修订）：早期表述为"未进行去标识化处理 → 红"，
但实操中大量"训练但已去标识化"与"不训练但未载明去标识化"的条目无法用这条规则区分。
现明确为：红色条件第③条只在数据实际用于训练/模型优化的前提下适用；
若条款明示不用于训练，则按第①条判定，不再因"未载明去标识化"单独升红。

判定示例（逐条对照）

以实际条目为例演示四项标准的应用。判定以条款实质为准，不以是否出现"训练"字样为准（检索须使用同义词组：训练/优化模型/提升模型/改进模型/模型训练/用于训练/优化训练/机器学习等）。

示例一：腾讯元宝（🟡）——加入式训练 + 留存不明确
- ① 默认不用于训练 ✓（2025-12 版协议 5.4：除非开启"体验优化计划"，否则不用于模型优化——加入式）
- ② 去标识化 ✓（加入计划后去标识化处理）
- ③ 留存明确 ≤30天 ✗（仅"目的所必需的最短时间"原则，无具体天数）
- ④ 版权归用户 ✓
- 结论：④②①✓ 但 ③✗ → 中风险（黄色标准"去标识化或使用边界不明确"）

示例二：CodeBuddy 个人版（🔴）——退出式训练 + 未去标识化 + 联系式退出
- 非代码输入输出默认参与优化模型（隐私声明 2.6.3-4，加密脱敏前提）
- 退出为联系式（第十一条），无产品内开关 → 退出困难
- 代码信息例外不训练，但其他内容未去标识化
- 结论：训练默认 + 联系式退出 + 未去标识化 → 高风险（红色标准"未去标识化处理"+"退出困难"）

示例三：ima（🟢→🟡 校准案例）
- 知识库数据明确不用于模型训练 ✓、问答记录 90 天 ✓
- 但去标识化未说明 ✗、版权归属未核实 ✗
- 结论：按严格四项口径 中风险（本库曾标绿，校验脚本推导后校准）

校验脚本会校验绿色四项条件并在不满足时告警；黄色/红色结论仍需结合条款证据人工判断，详情页的推导清单仅作复核参考。

核实方法

核实流程

  1. 访问官方政策页面：直接访问各产品的官方隐私政策 URL
  2. 定位关键条款：查找关于"数据使用"、"模型训练"、"数据保留"的章节
  3. 提取关键信息：
    - 是否明确说明使用/不使用用户数据训练
    - 默认状态（开启/关闭）
    - 是否提供退出机制及操作方法
    - 数据留存期限
    - 去标识化措施
    - 版权归属
  4. 交叉验证：对照产品设置界面，验证政策描述与实际操作是否一致
  5. 记录核实日期：每次核实后更新 last_verified 字段

核实要点

  • 优先查看最新版本的隐私政策
  • 注意区分个人版和企业版的不同政策
  • 关注政策更新日期，确保使用最新版本
  • 对于中国产品，同时查阅《个人信息保护法》合规声明

建议核实周期

  • 常规核实：每月一次，检查所有产品的政策页面是否有更新
  • 自动监控：每周运行 scripts/check_updates.py，检测政策页面内容变化
  • 事件驱动：当媒体报道某产品政策变更时，立即手动核实
  • 版本更新：当产品发布重大版本更新时，重新核实相关政策

数据字段说明

site/data/policies/{id}.json 是每个产品唯一的数据源；site/data/products.json 只维护产品 ID 的排列顺序与项目元信息，不再重复存储产品数据。

policies/{id}.json 顶层字段

字段 说明
id 产品唯一标识符（必须与文件名一致）
name 产品名称
company 所属公司
region 所属地区
description 产品简介
policy_url 官方隐私政策 URL（监控脚本抓取目标）
sources 可选的补充来源注册表，每项含 id、role、url、monitored
last_verified 最后人工核实日期（YYYY-MM-DD）
versions 包含 toc 和 tob 两个版本的详细政策
timeline 政策变更时间线
analysis_summary 分析摘要
key_findings 关键发现（数组）
recommendations 使用建议（数组）
icon / product_url 展示用图标与产品主页（可选）

versions.toc / versions.tob 字段

字段 说明
used_for_training 兼容字段：是否使用用户数据训练（布尔值）
training_status 语义化训练结论：explicit_yes / explicit_no / default_on_opt_out / default_off_opt_in / unknown / inferred
training_note 训练说明
default_state 默认状态（默认开启/默认关闭）
opt_out 退出机制（设置开关/邮件申请/无需退出等）
opt_out_method 退出操作说明
deidentified 是否去标识化（布尔值）
data_retention 数据留存期限
copyright 版权归属
risk_level 风险等级（green/yellow/red）
key_clauses 关键条款摘录（数组）
policy_link 该版本政策链接
label 版本标签（详情页标签页文案）

局限性说明

  1. 政策解读主观性：隐私政策的语言可能模糊，不同人可能有不同解读
  2. 时效性：各产品政策可能随时变更，本数据可能滞后
  3. 地域差异：同一产品在不同地区可能有不同的政策（如 GDPR vs 中国《个保法》）
  4. 功能差异：同一产品的不同功能模块可能适用不同政策
  5. 间接使用：部分产品可能通过关联公司间接使用数据，难以完全追踪
  6. 动态变化：产品的设置选项可能随版本更新而变化
  7. 语言限制：部分国外产品的政策以英文为主，翻译可能存在偏差

重要提醒：本数据仅供参考，不构成法律建议。在做出重要决策前，请咨询专业法律人士并查阅最新的官方政策。
